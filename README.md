# تشاليح المملكة

نموذج أولي تفاعلي لمنصة تربط المشتري بالتشاليح ومحلات قطع الغيار في المملكة، والدفع عن طريق المنصة بضمان.

**الرابط:** https://plus95a.github.io/tashaleeh/

## وش فيه
- سيارتي برقم الهيكل (VIN) وفحص توافق القطع
- بحث يفهم لهجة السوق (شمعة، اسطب، سلف، دينمو، كمبروسر...)
- طلب جماعي يوصل لكل التشاليح وتقارن العروض
- الصيّاد: شخص يدوّر القطعة النادرة عنك
- دفع بضمان المنصة، مدة فحص 48 ساعة، ونزاعات
- محادثة تخفي أرقام الجوال تلقائياً
- لوحة التشليح: الطلبات الواردة، العروض، المخزون، إضافة سيارة كاملة، المحفظة
- بيع السيارة التالفة للتشاليح

## ملاحظة
هذا نموذج واجهة فقط: كل البيانات تجريبية وتنحفظ في متصفح كل مستخدم، والدفع والعروض محاكاة. النسخة الفعلية تحتاج خادم وقاعدة بيانات وبوابة دفع حقيقية.
