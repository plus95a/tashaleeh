# تشاليح المملكة

منصة تربط المشتري بالتشاليح ومحلات قطع الغيار في المملكة، والدفع عن طريق المنصة بضمان.

**الموقع:** https://plus95a.github.io/tashaleeh/

## المزايا
- سيارتي برقم الهيكل (VIN) وفحص توافق القطع
- بحث يفهم لهجة السوق (شمعة، اسطب، سلف، دينمو، كمبروسر...)
- طلب جماعي يوصل لكل التشاليح وتقارن العروض
- المندوب: يدوّر القطعة النادرة عنك
- دفع بضمان المنصة ومدة فحص 48 ساعة
- محادثة تخفي أرقام الجوال تلقائياً
- لوحة للتشاليح ومحلات القطع: الطلبات الواردة، العروض، المخزون، المحفظة
- بيع السيارة التالفة للتشاليح

## تقنياً
الواجهة حالياً ملف HTML واحد يشتغل بالكامل في المتصفح. ربط الخادم وقاعدة البيانات وبوابة الدفع في المرحلة الجاية.
